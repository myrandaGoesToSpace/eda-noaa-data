# EDA for NOAA Data

by Myranda U. Shirk

Repository of example notebooks for accessing and visualizing NOAA data. 

## Getting Started

To get started with coding, download the notebooks in either the R or Python folders. 

To get an introduction on the materials, see the slides (PDF or PPTX format)
